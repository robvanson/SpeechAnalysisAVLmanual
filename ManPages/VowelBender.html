VowelBender

A Praat script to simulate vowel space changes after oral cancer treatment.

Running the script

When running the script, a form will appear with the following fields:

• Title: The title of the current conversion, will become the name of the output file.
• Gender: Indicate whether the speaker is a Female or Male. Gender affects the formant tracking
• Log: Store all values also in a semicolon-separated-values text file. This csv file is readable by VowelTriangle.praat
• Formant Algorithm: Select the method to calculate the formant values: Robust or Burg.
• i schwa F2 fraction (%): The size of the /i/-/ə/ (front) corner of the vowel triangle along the F2 axis in percent of the standard value.
• u schwa F2 fraction (%): The size of the /u/-/ə/ (back) corner of the vowel triangle along the F2 axis in percent of the standard value.
• a i F1 fraction (%): the size of the /i/-/a/ (close-open) dimension of the vowel triangle along the F1 axis in percent of the standard value.
• Smoothing Time (sec): The time dimension of the smoothing low pass filter of the formant tracks, in seconds.
• Source Signal: Use either standard Praat Phonation or a "whithened" LPC error signal. A low order (inverse filtered) LPC error signal tends to contain remnants of the original formants, which would defeat the purpose of VowelBender. Therefore, VowelBencer will use tripple the normal LPC order to extract trhe LPC error signal.

Buttons:

• Undo: Erase the form.
• Stop: Abort the script.
• Help: Open this manual instead of running the script.
• Open: Open an audio file and perform the manipulations specified in the form, or open a semicolon or tab-separated table with the specifications given in the rows.
